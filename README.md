# the harry's — система управления сетью (V20)

Внутренняя ERP/операционная система сети the harry's: филиалы Magic City, High Town, Cyber Arena и Цех.

## Запуск

Откройте `index.html` в браузере (Chrome / Edge). Сервер не нужен — данные хранятся в браузере (localStorage).
