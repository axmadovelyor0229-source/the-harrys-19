Проверены 1440, 1280, 1024, 768, 430, 390 px: горизонтальной прокрутки страницы нет ни в одном разделе. На телефоне — меню-бургер (закрывается после выбора и по Esc), модальные окна-шторки с закреплёнными кнопками, таблицы-карточки, кнопка «Выйти» доступна.

## 6. Только для серверного этапа (backend / VPS)

- Хранение данных: сейчас всё в localStorage одного браузера — данные не синхронизируются между устройствами и сотрудниками. Нужна БД и API.
- Пароли хранятся открытым текстом в localStorage — нужна серверная авторизация, хеширование, сессии/токены, сброс пароля.
- Права проверяются только в браузере — на сервере их нужно проверять повторно.
- Файлы (договоры аренды, фото задач и обращений) хранятся как base64 в localStorage (лимит ~5 МБ) — нужно файловое хранилище.
- Реальная интеграция с iiko (продажи, ТТК, списание по техкартам) — сейчас продажи вводятся вручную, CEO-выручка дополняется демо-моделью в дни без продаж.
- Фото в инвентаризации, уведомления (Telegram/push) о заявках, обращениях и платежах.
- Банковские/кассовые выписки для автоматической сверки денег компании; бухгалтерский экспорт.
- Резервное копирование и журнал аудита на сервере (сейчас журнал можно очистить, очистив браузер).
- Настоящий .xlsx (сейчас .xls в формате HTML — Excel открывает его с предупреждением о формате; это ограничение без библиотек/сервера).
